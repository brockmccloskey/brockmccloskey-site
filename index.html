I help software teams make complex products easier to understand.

How I help software teams

Make documentation maintainable

Use reusable content, clear structure, Git-based workflows, and better publishing processes so updates are easier and mistakes are less likely.

Reduce documentation debt

Turn neglected, incomplete, inconsistent, or hard-to-maintain documentation into something teams and customers can rely on.

Use AI carefully

Apply AI to planning, release notes, impact analysis, and research without handing accuracy over to a machine.

Current focus

I'm especially interested in roles where documentation is treated as part of the product system: docs-as-code, AI-assisted authoring, reusable content, publishing pipelines, knowledge systems, and documentation platforms that scale with the product.
