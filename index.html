What I do

I build documentation systems, not just documentation.

My work usually starts when documentation has become difficult to maintain, hard to navigate, outdated, inconsistent, or dependent on too few people. I help teams untangle the system, improve the architecture, and create repeatable workflows that make documentation easier to publish and sustain.

I bring 20+ years of enterprise documentation experience across MadCap Flare, HTML5 Help, CSS, Git, GitHub, GitLab, Azure DevOps, localization, release documentation, and AI-assisted documentation workflows.

Selected case studies

Documentation modernization in the wild

Trintech · AI Workflow Modernization

Kept documentation moving after a 66% team reduction

As the sole technical writer supporting six enterprise software products, I redesigned documentation workflows and integrated AI-assisted processes into release planning, documentation impact analysis, and first-draft content development.

  • Managed dozens of MadCap Flare projects across HTML5 Help, PDF, and release documentation.
  • Partnered with Product Management to improve Azure DevOps documentation workflows.
  • Implemented Google Analytics (GA4) for customer-facing Help systems to enable usage analysis and data-informed improvements.

NextAxiom · Documentation Rescue

Turned a duplicated, aging Help system into reusable architecture

Modernized documentation for a configurable enterprise platform used in regulated industries. The work focused on reducing documentation debt, standardizing terminology, and making shared product information easier to maintain.

  • Designed reusable, widget-based documentation architecture with nearly 100 snippets.
  • Replaced centralized property references with more context-sensitive documentation.
  • Introduced GitLab repositories and version control into the documentation workflow.

Equinix · Documentation Operations

Built infrastructure for a growing documentation organization

Joined a newly formed documentation organization and helped build the publishing systems, repository structure, localization workflows, and team processes needed to support enterprise-scale documentation delivery.

  • Supported approximately 20 products and a documentation team that grew to about 15 writers.
  • Established and administered approximately 25 GitHub repositories.
  • Managed staging, production, publishing, and multilingual documentation workflows.
