Case Study Themes

Patterns from years of documentation work.

Enterprise Documentation Infrastructure

Challenge: A growing documentation organization needed infrastructure that could support many products, writers, repositories, and publishing outputs.

Approach: Built publishing workflows, administered Git repositories, supported localization, and helped standardize documentation operations.

Outcome: Created a scalable documentation ecosystem supporting approximately 20 enterprise products and a team that grew to approximately 15 writers.

Reusable Content Architecture

Challenge: A highly configurable software platform had years of duplicated, inconsistent, and hard-to-maintain documentation.

Approach: Designed reusable content architecture using nearly 100 snippets and reorganized information around context-sensitive widget documentation.

Outcome: Reduced duplication, improved consistency, and made shared product information easier to maintain across the help system.

AI-Assisted Documentation Workflow

Challenge: Documentation delivery had to continue across six enterprise products after a documentation team reduction.

Approach: Introduced AI-assisted workflows using Azure DevOps and Codex for documentation planning, release notes, and impact analysis.

Outcome: Maintained delivery while improving how documentation requests and release activities were planned and tracked.
