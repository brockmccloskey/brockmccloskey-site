Technologies I've Grown With

The tools have changed. The goal has not: accurate, maintainable documentation customers can trust.

  1. Commodore VIC-20, Commodore 64, and early PCs. My interest in computers began early, copying BASIC programs from magazines and learning that technology was something I could explore hands-on.
  2. FrameMaker. My entry point into professional technical writing and enterprise publishing.
  3. Structured Authoring & DITA. Learned to think beyond pages and toward modular content, reuse, and scalable information architecture.
  4. MadCap Flare. The technology that transformed my career. I use Flare as a platform for information architecture, content reuse, CSS customization, responsive Help, PDF development, Git integration, localization, and documentation operations.
  5. Git. Adopted Git as part of modern documentation work, including repository setup, authentication, GitHub, GitLab, Azure DevOps Repos, source control workflows, and Flare integration.
  6. Docs-as-Code. Continuing to move documentation closer to software development practices through Git-based workflows, Markdown, source control, and maintainable documentation processes.
  7. AI. My newest chapter. I use AI as a documentation partner for release notes, documentation planning, workflow analysis, and research while keeping accuracy and judgment in human hands.
