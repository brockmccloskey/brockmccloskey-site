Equinix · Documentation Operations

Building repository and publishing infrastructure for roughly 20 products

A newly formed documentation organization needed more than content. It needed the systems, standards, repositories, publishing environments, and localization workflows required to operate at enterprise scale.

Equinix

Focus

Tools & methods

The challenge

What needed to change

The documentation team grew rapidly while supporting a broad product portfolio and unified customer deliverables. Without a coherent operating model, documentation repositories, publishing pipelines, staging and production environments, and multilingual release workflows could easily become fragmented.

The approach

Building a better operating model

  • Established and administered approximately 25 GitHub repositories.
  • Developed Git workflows, trained writers to use version control with MadCap Flare, and became the team's primary resource for troubleshooting Git repositories and Git/Flare integration issues.
  • Designed and maintained publishing infrastructure supporting roughly 20 products and a team of about 15 writers.
  • Managed staging and production delivery across multiple documentation projects.
  • Supported localization workflows and multilingual publishing.
  • Helped redesign the customer Help experience across the product portfolio.

The result

What the work made possible

  • Provided a scalable operating foundation for a growing documentation team.
  • Improved consistency across repositories and publishing workflows.
  • Supported unified customer deliverables across a large product portfolio.
  • Made documentation operations a managed system rather than a collection of individual projects.
Why this matters

The visible deliverable is documentation. The durable value is a system that makes future documentation easier to produce, maintain, and trust.
