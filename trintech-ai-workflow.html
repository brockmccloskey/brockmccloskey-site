Trintech · AI Workflow Modernization

Maintaining six enterprise products after a 66% documentation team reduction

A documentation portfolio that had previously been supported by three writers needed to continue moving with one. The answer could not simply be longer hours. The workflow itself had to change.

Organization

Trintech

Focus

AI Workflow Modernization

Tools & methods

MadCap FlareAzure DevOpsCodexHTML5 HelpPDFGoogle AnalyticsRelease notes

The challenge

What needed to change

The documentation team was reduced from three writers to one while the product portfolio, release cadence, and customer expectations remained. Dozens of MadCap Flare projects, HTML5 Help systems, PDF outputs, and release documentation still needed consistent attention.

The approach

Building a better operating model

  • Redesigned Azure DevOps documentation workflows with Product Management so documentation needs were identified earlier and more consistently.
  • Integrated AI (Codex) into documentation planning, impact analysis, release note preparation, and first-draft content development.
  • Maintained a reusable publishing environment across multiple products and output formats.
  • Used Google Analytics to create a path toward usage-informed documentation improvements.
  • Kept human review, product understanding, and editorial judgment at the center of the workflow.

The result

What the work made possible

  • Continued documentation delivery across six enterprise software products with one writer.
  • Reduced manual discovery work during release planning.
  • Created repeatable AI-assisted workflows instead of isolated experiments.
  • Preserved documentation quality while the operating model changed dramatically.
Why this matters

The visible deliverable is documentation. The durable value is a system that makes future documentation easier to produce, maintain, and trust.
